# Chromium Download center

This tool is capable of downloading and installing Chromium stable, dev and latest withing one GUI, you can switch really fast from version to a different version.

### Important

This project is **NOT** affiliated with The Chromium Project or Google LLC.

This tool is free to use but i made it for personal use, updates might be slow due to this.

## Download

check the releases page for the installer and portable version: [Latest release](https://github.com/Mealman1551/chromium-dl-center/releases/latest)

## Build yourself

```powershell
winget install git.git
git clone https://github.com/Mealman1551/chromium-dl-center.git
cd chromium-dl-center
pip install -r requirements.txt
./build.bat
```
